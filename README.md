# WikiDeJogos
Uma wiki interativa de jogos desenvolvida em HTML, CSS e JavaScript, com gerenciamento de dados em JSON e suporte a script de fallback em Python.

# 🎮 Wiki de Jogos

Uma plataforma web interativa e leve dedicada a catalogar e exibir informações sobre diversos jogos. O projeto foi desenvolvido com tecnologias web modernas (HTML5, CSS3 e JavaScript vanilla) e conta com estruturação de dados em JSON e automação em Python.

## 🚀 Funcionalidades

* **Catálogo Dinâmico:** Exibição de jogos com informações detalhadas.
* **Busca e Filtros:** Facilidade para encontrar títulos específicos rapidamente.
* **Design Responsivo:** Interface adaptada para diferentes tamanhos de tela (desktop e dispositivos móveis).
* **Gerenciamento de Dados:** Armazenamento estruturado utilizando arquivos JSON e JavaScript.
* **Automação (Python):** Script utilitário para geração de fallbacks.
